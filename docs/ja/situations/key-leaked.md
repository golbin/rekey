# キーが漏れた

キーがコミット、ログ、スクリーンショットなどに含まれてしまった場合です。

```bash
rekey where <キー名>      # 名前が分からなければ rekey ls '*.openai' や rekey ls project:shop で探す
rekey rotate <キー名>
```

聞かれたらサービスを一つずつ再デプロイし、**古いキーをいま無効化するか聞かれたら y** を押します。漏れたキーを様子見する理由はありません。聞かれずに終わった場合は、書き込みに失敗したか再デプロイしていない使用先があります。表示されたコマンドで解決してデプロイしてから `rekey revoke <キー名>` を実行してください。

そのあと：
- git の履歴に残ったキーはすでに無効なので、履歴を書き換える必要はありません。公開リポジトリだった場合は、サービスの利用履歴に見覚えのない呼び出しがないか確認してください。
- rekey が知らない場所（ほかのリポジトリ、個人の PC、外部サービスの設定画面）にも同じキーを置いていたなら、そこも変更し、その場所もテンプレートに追加してください。
