# 密钥泄露了

密钥被提交进代码、出现在日志或截图里。

```bash
rekey where <密钥名>      # 不知道名字？试试 rekey ls 'openai.*'
rekey rotate <密钥名>
```

完成后，**被问到是否现在吊销旧密钥时选 y**。泄露的密钥没有理由再等。如果没有被问到，说明有使用处写入失败：按提示的命令解决后，运行 `rekey revoke <密钥名>`。

然后：
- 留在 git 历史中的密钥已被吊销，无需改写历史。如果仓库是公开的，请检查服务的使用记录中是否有陌生的调用。
- 如果你还把这个密钥放在 rekey 不知道的地方（其他仓库、个人电脑、第三方后台），也去那里更换，并把那个地方加到模板里。
