# 키 하나가 유출됐다

커밋에 키가 섞였거나, 로그·스크린샷에 키가 노출된 경우입니다.

```bash
rekey where <키 이름>      # 이름을 모르면 rekey ls 'openai.*' 처럼 찾기
rekey rotate <키 이름>
```

교체가 끝나면 **"옛 키를 지금 폐기할까요?"에 y**를 누릅니다. 유출된 키는 지켜볼 이유가 없습니다. 묻지 않고 끝났다면 실패한 사용처가 있는 것이니, 결과에 나온 명령으로 해결한 뒤 `rekey revoke <키 이름>`을 실행하세요.

그다음:
- git 기록에 남은 키는 이미 폐기됐으니 기록을 지울 필요는 없습니다. 공개 저장소였다면 서비스의 사용 기록에서 이상한 호출이 없었는지 확인하세요.
- rekey가 모르는 곳(다른 저장소, 개인 PC, 외부 서비스 설정)에 같은 키를 넣어 둔 적이 있다면 그곳도 바꾸고, 앞으로는 그곳도 템플릿에 추가해 두세요.
